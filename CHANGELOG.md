# What's new

The newest version is first. Each version here matches a release on the [Releases page](https://github.com/heyshantanugupta/autosmm/releases).

## v1.1.0

- **Start from your website.** Paste your address and AutoSMM fills in a first draft of your brief from what the page says. It only fills empty fields, drops anything the page does not support, and lists what the page did not say so you can add it.
- **Light and dark mode button** in the top right corner. It starts from your computer's setting and remembers your choice.
- The TheInterviews.ai example brief is no longer part of the app.
- Cleaner README, and this changelog.

## v1.0.2

- Installer file names now include the version, for example `AutoSMM-1.0.2-mac-arm64.dmg`.
- The README download buttons update themselves after each release.
- The model list is a dropdown for every provider, with "Other" for any model id and a "Check available models" button.
- Providers are grouped by how you usually pay, instead of labeled free or paid.
- Fixed the extra Dock icon on Mac.

## v1.0.0

- First release: strategy, drafts for 7 platforms, claim checks, tracked links, image prompts for Gemini and ChatGPT, PDF and Word export, and saving your brief as a file.
- Providers: Google Gemini, Groq, OpenRouter, OpenAI ChatGPT, xAI Grok, Anthropic Claude and Ollama.
- Desktop apps for Windows and Mac.
